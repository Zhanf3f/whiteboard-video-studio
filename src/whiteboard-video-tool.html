分镜脚本格式说明（给 AI 看的）
每幕一个对象：text 字幕、emotion（sad/happy/love/think，可省）、palette 两个点缀色（可省，阿健风下不给 palette 即默认单色深灰）、duration 秒（可省）、elements 元素列表、labels 手写标注、arrows 连接箭头。
元素字段：name、x/y（0~1，y ≤0.82 避开底部字幕区）、scale（主体 2.8~3.6，辅助 1.3~2.0）。第一个元素为主体，先画。
标注字段：{"text":"¥1300","x":0.7,"y":0.3,"size":48,"role":1}——把数字/关键词直接写进画面，role 0=黑 1=A色 2=B色。
箭头字段：{"from":[0.3,0.4],"to":[0.65,0.4],"role":2,"curve":0.12}——在两个元素间画手绘箭头表达关系（钱流向/因果/指向）。
构图铁律：一幕=一张完整示意图，元素+标注+箭头必须共同讲清这一句；数字必须写出来；元素之间要有关系，禁止四角撒零件。
自定义绘画（首选）：元素带 strokes 数组即为 AI 逐笔作画，不受元素库限制，局部坐标 0~100（50,50 为中心，由 x/y/scale 定位缩放）。每笔可用：{"path":[[x,y],...]} 平滑曲线（"close":true 闭合、"sharp":true 折线）、{"line":[[x1,y1],[x2,y2]]}、{"circle":[cx,cy,r]}、{"ellipse":[cx,cy,rx,ry,rot]}、{"arc":[cx,cy,r,a0,a1]}；通用 "role":1/2 点缀色、"fill":true 淡彩填充。整幕定制画面时建议 "ambient":false 并自画地面。
可用元素：person 人物 / letter 信纸 / cloud 乌云 / house 房子 / book 书本 / clock 时钟 / phone 电话 / bulb 灯泡 / road 道路 / mountain 山 / plant 植物 / heart 心形 / eye 眼睛 / money 钱 / chain 锁链 / boat 小船 / star 星星 / sun 太阳 / moon 月亮 / smiley 笑脸 / sadface 哭脸 / question 问号 / bubble 对话框 / arrow 箭头 / coffee 咖啡 / city 城市 / gov 政府大楼 / scale 天平 / pie 饼图 / chart 柱状图 / wallet 钱包 / tag 价签 / percent 百分号 / cart 购物车 / family 一家三口 / oldman 老人
